# Playwright MCP 用 転記プロンプト集

GitHub Copilot に Playwright MCP サーバーを接続した状態で、以下のプロンプトをそのまま貼り付けて利用します。
`<エンドポイント>` は Azure Static Web Apps のデプロイ先 URL (例: `https://swa-scm-core-handson.azurestaticapps.net`) に置き換えてください。

---

## 1. 基本プロンプト (PDF 1 件を転記する)

```text
あなたは受発注業務のオペレーターです。Playwright MCP を使って、以下の作業を実施してください。

【入力ファイル】
samples/pdf/order-001.pdf

【転記先】
<エンドポイント>  (SCM-CORE 受発注管理システムの「受発注データ登録」画面)

【手順】
1. samples/pdf/order-001.pdf を読み取り、次の項目の値を抽出して一覧で提示してください。
   - 注文番号 / 受注日 (注文日) / 取引先コード / 納品希望日 / 商品コード / 数量 / 単価 / 通貨
   - 支払条件 / 出荷方法 / 担当者名 / 検収要否 / 備考
2. Playwright で <エンドポイント> を開きます。
3. 抽出した値を各入力欄に転記します。
   - 「注文番号」「担当者名」「備考」はテキスト入力
   - 「受注日」「納品希望日」は日付入力 (YYYY-MM-DD 形式で入力すること。ファイル上が 2026/04/06 表記なら 2026-04-06)
   - 「取引先」「商品コード」「通貨」「支払条件」はプルダウン選択
     (取引先・商品コードの選択肢は「C-1001 : 山田製作所」のようにコードと名称が併記されています。ファイル上のコードと一致する選択肢を選ぶこと)
   - 「数量」「単価 (円)」は数値入力 (カンマ区切りは除去して半角数字のみ入力すること)
   - 「出荷方法」はラジオボタン、「検収要否」はチェックボックス (検収が「必要」の場合のみチェック)
4. 入力後「受発注データの登録」ボタンを押します。
5. 登録確認画面 ([ORD-0101]) が表示されたら、表示されている全項目とファイルの値が一致しているか 1 項目ずつ突き合わせて検証し、結果を報告してください。
6. すべて一致している場合のみ「登録を確定する」ボタンを押します。不一致があれば確定せず、「入力画面に戻る」を押して修正してください。
7. 登録完了画面 ([ORD-0102]) のメッセージと、画面下部の「登録済み受発注データ」一覧に追加された行の内容を報告してください。

【禁止事項】
- ファイルに記載されていない値を推測で入力しないこと。
- 確認画面の検証を省略して登録を確定しないこと。
```

## 2. Excel を転記するプロンプト

```text
Playwright MCP を使って、samples/excel/order-101.xlsx の受発注内容を <エンドポイント> の SCM-CORE 受発注管理システムに転記してください。

Excel はシートが分かれている場合やラベルが英語表記 (Order No. / Customer Code など) の場合があります。
以下の対応表に従って値を読み取り、Web アプリの入力欄にマッピングしてください。

| ファイル上のラベル例                         | Web アプリの入力欄 | 形式             |
| -------------------------------------------- | ------------------ | ---------------- |
| 注文番号 / Order No. / 受注NO                | 注文番号           | テキスト         |
| 受注日 / 注文日 / Order Date / 受注年月日    | 受注日             | 日付 YYYY-MM-DD  |
| 取引先コード / Customer Code / 得意先CD      | 取引先             | プルダウン       |
| 納品希望日 / Requested Delivery Date / 希望納期 | 納品希望日      | 日付 YYYY-MM-DD  |
| 商品コード / Item Code / 品目CD              | 商品コード         | プルダウン       |
| 数量 / QTY / 受注数                          | 数量               | 数値             |
| 単価 / Unit Price / 売単価                   | 単価 (円)          | 数値             |
| 通貨 / Currency / 通貨CD                     | 通貨               | プルダウン       |
| 支払条件 / Payment Terms / お支払条件        | 支払条件           | プルダウン       |
| 出荷方法 / Shipping / 配送区分               | 出荷方法           | ラジオボタン     |
| 検収要否 / Inspection / 検収                 | 検収要否           | チェックボックス |
| 担当者名 / Person In Charge / 担当           | 担当者名           | テキスト         |
| 備考 / Remarks / 摘要 / 連絡事項             | 備考               | テキストエリア   |

登録ボタン → 確認画面での突合検証 → 登録確定、の順に進め、各ステップの結果を報告してください。
```

## 3. 6 ファイルを一括で転記するプロンプト

```text
Playwright MCP を使って、samples/pdf 配下の 3 つの PDF と samples/excel 配下の 3 つの Excel、
合計 6 件の受発注データを <エンドポイント> の SCM-CORE 受発注管理システムへ順番に転記してください。

各ファイルについて次を繰り返します。
1. ファイルから転記対象項目 (注文番号 / 受注日 / 取引先 / 納品希望日 / 商品コード / 数量 / 単価 / 通貨 /
   支払条件 / 出荷方法 / 担当者名 / 検収要否 / 備考) を抽出する
2. 入力画面に転記する (日付は YYYY-MM-DD、数値はカンマなしの半角数字)
3. 「受発注データの登録」を押し、確認画面で全項目を突合する
4. 一致していれば「登録を確定する」を押す
5. 完了画面のメッセージを記録し、「続けて登録する」で次のファイルに進む

すべて完了したら、画面下部の「登録済み受発注データ」一覧に 6 件が並んでいることをスクリーンショットで確認し、
ファイル名・注文番号・登録結果 (成功 / 失敗) の一覧表を作成して報告してください。
```

## 4. 異常系を体験するプロンプト (任意)

```text
Playwright MCP を使って <エンドポイント> を開き、必須項目のバリデーションが機能することを確認してください。

1. 「注文番号」だけを入力し、他は未入力のまま「受発注データの登録」ボタンを押す
2. 確認画面に遷移しないこと、および未入力の必須項目それぞれにエラーメッセージが表示されることを確認する
3. 表示されたエラーメッセージを一覧で報告する
4. その後、samples/pdf/order-002.pdf の内容を正しく転記し、登録まで完了させる
```
